# E-Commerce Chatbot (SDN150S)

A Java desktop chatbot for an e-commerce platform, built for Software Design 1
(SDN150S), CPUT, Faculty of Engineering and the Built Environment.

## What it does
- Answers frequently asked questions
- Helps users search for products
- Provides basic order tracking information
